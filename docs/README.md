## 和代码层 README 的关系

```text
docs/项目分层介绍.md          ← 全局「地图」
   ├─ chatbot-springboot/README.md   ← 后端这一层怎么读代码
   ├─ chatbot-vue3/README.md         ← 前端这一层怎么读代码
   └─ docs/本 README + 各专项 md     ← 演示 / 建库 / 改造计划
```

- **分层介绍**讲「系统有哪些层」。  
- **专项 md**讲「某一层或某一专题的细节」。  
- **前后端 README**讲「这个工程目录里文件怎么摆、怎么跑」。

改造计划文**不能**代替分层图；分层图**不能**代替演示剧本。
