# 接入层

接入层是 HTTP 入口。代码在 `chatbot-springboot` 的 `com.quanxiaoha.ai.robot.controller`。这一层把请求交给后面的包，不在 Controller 里写查单规则和审批规则。

总览：[架构说明.md](../../架构说明.md)。

## 三个 Controller

| 类 | 路径前缀 | 谁在调 | 要不要后台 JWT |
|----|----------|--------|----------------|
| `AiCustomerServiceController` | `/customer-service` | 买家 Widget、知识库上传 | 不要 |
| `ChatController` | `/chat` | 内部测试台 | 不要 |
| `AdminCommerceController` | `/admin` | 商家后台里的交易、收件箱、轨迹 | 除登录外都要 |
| `AdminPlatformController` | 方法上写完整路径 `/admin/...` | 会话、审计、评测、工作流、多语言 | 要 |

`AdminAuthInterceptor` 拦住 `/admin/**`，放行 `OPTIONS` 和 `/admin/auth/login`。请求头要有 `Authorization`。没有或过期返回 401 和统一的 `Response` JSON。

## 买家接口

都在 `AiCustomerServiceController`。

| 方法 | 路径 | 作用 |
|------|------|------|
| POST | `/customer-service/chat/completion` | 客服 SSE。请求体有 `message`、`chatId`、`customerContact` |
| POST | `/customer-service/completion` | 上面的旧路径，行为相同 |
| GET | `/customer-service/chat/{chatId}/messages` | 拉这条会话的消息，含人工回复 |
| POST | `/customer-service/file/check` | 上传前检查文件 |
| POST | `/customer-service/file/upload-chunk` | 分片上传 |
| POST | `/customer-service/file/merge-chunk` | 合并分片 |
| POST | `/customer-service/file/list` | 知识库文件列表 |
| POST | `/customer-service/file/update` | 改文件信息 |
| POST | `/customer-service/file/delete` | 删除文件 |

`rag.agent.enabled=true` 时，对话进 `AgentChatService`。关掉则走 Advisor RAG，不再挂工具。两种模式互斥，避免同一问检索两次。

`customerContact` 必须从请求体传到 `AgentChatService`。Widget 里填的邮箱只存在这个字段里，消息正文里不一定有。

## 测试台接口

都在 `ChatController`，前缀 `/chat`。

| 方法 | 路径 | 作用 |
|------|------|------|
| POST | `/chat/new` | 新建测试对话 |
| POST | `/chat/completion` | 测试台 SSE |
| POST | `/chat/list` | 历史会话 |
| POST | `/chat/message/list` | 某条会话的消息 |
| POST | `/chat/summary/rename` | 改标题 |
| POST | `/chat/delete` | 删除会话 |

这是研发调试用的对话，不是买家 Widget，也不是商家收件箱。

## 后台接口

登录：`POST /admin/auth/login`，返回 token、显示名、角色。

交易和作业：

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/admin/dashboard/summary` | 概览计数 |
| GET | `/admin/orders`、`/admin/orders/{orderNo}` | 订单列表和明细 |
| GET | `/admin/products` | 商品 |
| GET | `/admin/customers` | 客户 |
| GET | `/admin/actions` | 审批列表，可用 `status` 过滤 |
| POST | `/admin/actions/{id}/review` | 通过或驳回。角色必须是 supervisor |
| GET | `/admin/tickets`、`/admin/tickets/{id}` | 工单 |
| GET | `/admin/inbox/{chatId}/messages` | 收件箱里的消息 |
| POST | `/admin/tickets/{id}/takeover` | 接管 |
| POST | `/admin/tickets/{id}/reply` | 回复买家 |
| POST | `/admin/tickets/{id}/resolve` | 结单 |
| GET | `/admin/tool-logs` | 工具调用 |
| GET | `/admin/traces`、`/admin/traces/{runId}` | 轨迹 |
| POST | `/admin/rag/debug` | RAG 工作台检索 |

平台只读：

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/admin/conversations`、`/admin/conversations/{chatId}` | 会话记录 |
| GET | `/admin/audit` | 审计 |
| GET | `/admin/users` | 账号说明 |
| GET | `/admin/evals/summary` | 契约评测摘要，不调外部模型 |
| GET | `/admin/agent-workflow` | 分流和白名单说明 |
| GET | `/admin/multilingual` | 语种和翻译回退记录 |

## 这一层不做什么

- 不在 Controller 里比对邮箱和订单。
- 不在 Controller 里决定工具白名单。
- 不托管 Vue 页面。打开后端根地址不会得到后台界面。
