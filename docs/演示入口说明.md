# 小智AI · 演示入口说明

产品计划见：[商家客服运营平台全链路改造.md](./商家客服运营平台全链路改造.md)

## 三端入口

| 端 | URL（Hash 路由） | 说明 |
|----|------------------|------|
| 买家 Widget | `/#/widget` | 公开咨询组件，无后台 JWT |
| 内部测试台 | `/#/` | 研发调试：历史会话、模型、知识上传 |
| 商家运营后台 | `/#/admin/login` | `admin` / `123456` → 默认进数据概览 |

登录态是 HMAC JWT，重启后仍有效。`agent` / `agent123` 只能处理收件箱；`supervisor` / `super123` 与 `admin` 可以审批。

## 5 分钟剧本

1. Widget：邮箱 `zhangsan@example.com`，问 `ORD-10001` 物流
2. Widget：问退货政策，或英文 `What is the return policy?` → 引用卡（向量库或内置中英 FAQ）
3. Widget：申请退货 → 后台「动作审批」通过
4. Widget：转人工 → 「统一收件箱」接管回复
5. 「轨迹回放」看 triage / tool / response；「多语言证据」看语种

## 常用后台页

- `/#/admin` 概览
- `/#/admin/inbox` 收件箱
- `/#/admin/conversations` 会话记录
- `/#/admin/actions` 审批
- `/#/admin/customers` · `orders` · `products`
- `/#/admin/knowledge` 上传并看向量化状态
- `/#/admin/rag-workbench` · `traces` · `evals` · `agent-workflow`
- `/#/admin/multilingual` · `operations` · `audit` · `users`
